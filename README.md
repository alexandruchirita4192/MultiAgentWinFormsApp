# Multi-Agent WinForms Application

## New Team Presets

The app now supports applying agent-team presets from `App.config`.

- **Delta Force Team**: focused on forex automation workflows (Python ML/ONNX training, MT5 EA engineering, optimization, and parallel execution with unique magic numbers).
- **Army**: focused on daily-life operational support across finance, risk, planning, productivity, and knowledge management.

Select a preset from the new dropdown and click **Apply Team Preset** to replace active agents with that configuration.
